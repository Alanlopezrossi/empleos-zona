Cargar un aviso a la página

← Volver a las ofertas

Opción 1 · Pegar el aviso (sirve en el celular)

Copiá el texto del aviso (de Facebook, Instagram, WhatsApp, un cartel…) y pegalo acá.

Se abre GitHub con el aviso cargado: tocá Create (o "Submit new issue") y en un par de minutos aparece en la página, ordenado por la IA.

Opción 2 · Botón para la computadora (1 clic desde Facebook)

  1. Mostrá la barra de favoritos del navegador (Ctrl+Shift+B).
  2. Arrastrá este botón hasta la barra: ➕ Mandar a Empleos
  3. Cuando veas un aviso en un grupo: seleccioná el texto del posteo con el mouse y tocá el botón.
  4. Se abre GitHub con todo cargado: tocá Create.

Para que el link lleve al posteo exacto, abrilo primero (clic en la fecha del posteo) y después usá el botón. Si no, se guarda el link del grupo.
